🐉 Dragões - Game of Thrones
🌐 Sobre o projeto

Este é um projeto web interativo inspirado no universo de Game of Thrones, com foco nos dragões Targaryen. A aplicação permite visualizar diferentes dragões, alternando entre imagens e informações de forma dinâmica através da interação com botões.

Este projeto também marca meu retorno à programação após cerca de 2 anos sem praticar. Decidi retomar os estudos e recomeçar minha jornada no desenvolvimento web.

Durante esse processo, utilizei um código antigo como base e, com o auxílio de ferramentas de IA para tirar dúvidas e corrigir erros, consegui refatorar e melhorar o projeto enquanto reaprendia os conceitos de front-end.

🚀 Funcionalidades
Troca dinâmica entre diferentes dragões
Atualização de imagem, nome e descrição em tempo real
Interface simples e interativa
Layout responsivo para diferentes dispositivos
💻 Tecnologias utilizadas
HTML5
CSS3
JavaScript
